# Lab 2.2 - C-Style Arrays, Files, and Functions
In this lab, you will write functions to:
* Read values of type `double` from a file and store them in a C-style array.
* Sort the array of `double`.
* Write the contents of the array to a file.
* Swap two values. Your sorting function should call your swap function.

You may use any sorting algorithm that you would like. Selection sort from CISC 1115 will receive full credit even though it is not an efficient sorting algorithm.

Feel free to write a main function to test your functions. However, please comment out
your main function before submitting your code.
